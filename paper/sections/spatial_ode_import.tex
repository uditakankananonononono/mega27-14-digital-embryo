\subsection{An independent spatial SBML trajectory reproduces curves but not a strict patched peak claim}
A frozen validation unit imports an unchanged public spatial segment-polarity model, distinct from the reduced local Boolean network. The source checkout is \texttt{1962866c8d4750516be10978908fca2b333073a3} at \url{https://github.com/pmendes/models/tree/main/vonDassow2000}; the accompanying published reproducibility study is \url{https://www.frontiersin.org/journals/cell-and-developmental-biology/articles/10.3389/fcell.2023.1201673/full}. This one-by-four-cell SBML encodes the author's chosen timecourse1 parameters and initial conditions. Preregistration SHA256 is \path{6d352e2120c25400fd614ba37ee0d8805a0c7af1396634e01350827fd16f2b01}. No parameter search or spatial perturbation grid is added.

Using libRoadRunner 2.8.0, CVODE non-stiff mode, absolute tolerance $10^{-12}$ and relative tolerance $10^{-6}$ as in the source runner, the imported model is sampled from zero through 1100 in 221 steps of five time units. Twenty mRNA species (en, ci, hh, ptc and wg in four cells) are compared by exact identifiers and sample times with archived Tellurium and COPASI trajectories. All forty species/source comparisons pass the frozen scale-normalized maximum-error threshold $10^{-3}$; the largest error is $5.51535\times10^{-5}$. This is a numerical replay threshold, not a biological tolerance, and it certifies neither every protein trajectory nor steady-state stability.

The separate frozen strict endpoint-argmax criterion does not entirely pass. Wingless peaks in cell 2 (.8294253) and engrailed and hedgehog in cell 3 (.9999994 and .9999991), matching the published description. Patched instead has its largest computed endpoint in cell 4: .0072072277966 versus .0072072277802 in cell 2. The difference is only $1.63\times10^{-11}$, but changing the criterion after seeing this near-tie would erase a prespecified negative. The archived Tellurium endpoints also put cell 4 barely above cell 2 (.0072072278105 versus .0072072277942); archived COPASI rounds both to .00720723. Thus curve replay succeeds while a unique cell-2 patched maximum is not established by this strict criterion. This does not refute a qualitative description of high patched in cell 2, and it is not an importer-specific large discrepancy.

Source/SBML/reference hashes, every trajectory error, all endpoint values and the failed criterion remain in \path{results/spatial_ode_import_audit.json}; the fresh twenty-species simulation is in \path{results/spatial_ode_import_trajectory.csv}. The plan and runner are \path{experiments/spatial_ode_import_plan.json} and \path{experiments/spatial_ode_import_audit.py}. Tests check identifier/time geometry, all frozen comparisons and the retained patched near-tie; source replay is run from the clean committed checkout. The imported source files themselves are not redistributed here.

This is one independently implemented spatial model at one published selected parameter and initial setting. It is not equivalence to the local Boolean reference, independent physiological validation, a robustness estimate or a proof of an attractor. The earlier Boolean counterfactual negatives remain unchanged. The content-page gate is uncertified.
