\subsection{Four-model comparison: nothing beats linear theory on the wavenumber shift}
Verdict \#19 asks for a systematic model comparison around the CNN's retracted win. On the cached 171-simulation Turing set, we predicted the relative position of the simulated wavenumber within the linearly unstable band under one protocol (6-fold CV, 2 seeds, relative RMSE): (i) linear theory's fastest mode scores 0.343; (ii) the CNN on the dispersion curve scores 0.339 - a statistically meaningless 1\% edge, confirming the n=58 retraction at n=171; (iii) an MLP on the four physical parameters scores 0.449; (iv) ridge regression on hand-built curve features (peak position, width, height, centroid) scores 1.240. The ordering is itself the finding: \textbf{the only features that matter are the ones linear theory already encodes}; parameter-space and curve-shape summaries add noise, not signal. The beyond-onset wavenumber upshift (87\% of sims, mean +0.88 $k^2$ units) is real but not learnable from any of these input views - a boundary result that converts the earlier ``CNN failure'' into a quantified statement about where linear theory's information content ends.
